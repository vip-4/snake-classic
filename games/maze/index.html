迷宫是什么？

迷宫（Maze）是一个免费的浏览器寻路游戏。使用递归回溯算法程序化生成迷宫，每次新局都不同。你需要从左上角起点移动到右下角终点，避开墙壁。

游戏使用原生 JavaScript 实现。支持三种尺寸、计时与最佳成绩记录、键盘与触屏操作。

In English: Maze is a free browser maze game. Procedurally generated, navigate from start to finish.

怎么玩迷宫

  1. 选择尺寸：小、中或大。
  2. 移动角色：方向键或点击屏幕移动。
  3. 到达终点：从左上角到右下角即获胜。
  4. 新局：点击新局重新生成迷宫。

核心规则

  • 从左上角起点出发，目标是右下角终点
  • 只能在通道内移动，不能穿越墙壁
  • 每次新局使用程序化算法生成新迷宫
  • 记录用时，保存每种尺寸的最佳成绩
  • 迷宫是经典游戏的原生实现，未复用第三方代码

无第三方依赖，纯原生 HTML/CSS/JS。

常见问题

关于迷宫

迷宫怎么操作？

使用方向键移动角色，从起点到达终点。

有几种尺寸？

三种：小、中、大，迷宫网格大小不同。

迷宫是随机生成的吗？

是的，每次新局使用递归回溯算法程序化生成。

成绩保存在哪里？

每种尺寸的最佳时间保存在浏览器 localStorage 中。
