扫雷经典版是什么？

扫雷经典版（Minesweeper Classic）是一个免费、开源的浏览器扫雷游戏，提供初级 9×9（10 颗雷）、中级 16×16（40 颗雷）和高级 16×24（75 颗雷）三档难度。首次点击的格子及其周围八格保证安全，数字表示相邻八格中的地雷数量；翻开所有安全格即获胜。

游戏使用原生 JavaScript 和 DOM 实现，支持鼠标点击、右键插旗、手机长按和旗标模式，并为每档难度记录本地最佳用时。页面不需要登录、下载或任何第三方服务，首次加载后可离线游玩。

In English: Minesweeper Classic is a free browser game with three board sizes, a guaranteed safe first click, flagging on desktop and mobile, and locally stored best times.

怎么玩扫雷

  1. 选难度：初级适合熟悉规则，中级考验推理，高级需要更长的排雷路线。
  2. 翻第一格：点击任意格子开始；首击及其周围八格保证没有地雷。
  3. 读数字：数字表示相邻八格里的地雷数；空白格会自动展开周围区域。
  4. 插旗：右键、长按或开启旗标模式，把确定有雷的格子标出来。
  5. 清空棋盘：翻开所有非地雷格即获胜；踩到地雷则本局结束。

核心规则

  • 地雷在首次翻开后生成，首击格及周围八格安全。
  • 数字表示相邻八格中的地雷数量，范围 1–8。
  • 空白格周围没有地雷，会自动展开相连的安全区域。
  • 旗标只用于标记，不改变格子内容；插错旗不会立即失败。
  • 翻开所有安全格即获胜；翻开地雷立即失败。
  • 计时从第一次翻开开始，最佳用时按难度分别保存。

高级棋盘为 16×24，在窄屏上可左右滑动查看。所有数据只保存在浏览器本地。

常见问题

关于扫雷经典版

第一次点击会踩雷吗？

不会。地雷在首次翻开后生成，并会排除首次点击的格子及其周围八格，因此第一格始终安全。

手机上怎么插旗？

可以长按格子约半秒，或点击“旗标模式”按钮后直接点击格子插旗。再次点击同一格可取消旗标。

三档难度分别有多少格子和地雷？

初级为 9×9 共 81 格、10 颗雷；中级为 16×16 共 256 格、40 颗雷；高级为 16×24 共 384 格、75 颗雷。

最佳成绩保存在哪里？

每档难度的最佳用时保存在浏览器 localStorage 中，不会上传。清除站点数据或更换设备后会重置。

扫雷的数字是什么意思？

数字表示该格子相邻的八个格子中地雷的数量。例如 3 表示周围八格里有三颗雷；空白格表示周围没有地雷，会自动展开相邻区域。
