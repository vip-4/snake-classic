Pong 是什么？

Pong（乒乓球）是一个免费的浏览器街机游戏，模拟桌球对战。双方控制挡板击球，球对出界对方得分，先达到 11 分获胜。

游戏使用原生 JavaScript 与 Canvas 2D 实现。支持双人同屏对战、三种球速、计分系统。

In English: Pong is a free browser arcade game. 2-player local multiplayer, first to 11 points wins.

怎么玩 Pong

  1. 控制挡板：左侧 W/S，右侧 ↑/↓ 移动。
  2. 击球：用挡板将球击回对方。
  3. 得分：球对出界对手得分。
  4. 获胜：先达到 11 分的一方获胜。

核心规则

  • 双方控制挡板，击球来回对打
  • 球对出界对手得分
  • 先达到 11 分获胜
  • 支持三种球速：慢 / 中 / 快
  • Pong 是经典街机游戏的原生实现，未复用第三方代码
