推箱子是什么？

推箱子（Sokoban）是一个免费的浏览器解谜游戏。推动箱子到目标点，经典关卡，支持撤销/重做、关卡选择、最少步数记录。方向键或 WASD 操作，手机使用屏幕按钮。

游戏使用 Canvas 2D 渲染。内置 50 个经典关卡，难度递增。每关最少步数保存在浏览器本地。

怎么玩推箱子

  1. 移动角色：方向键或 WASD 移动。
  2. 推箱子：走到箱子旁边，向箱子方向移动即可推动。
  3. 目标：将所有箱子推到目标点（圆点）上。
  4. 撤销：按 Z 撤销上一步，按 R 重置关卡。

核心规则

  • 推动箱子到目标点
  • 不能拉箱子，只能推
  • 箱子不能推到墙上或另一个箱子上
  • 所有箱子到达目标点即通关
  • 支持撤销和重置

推箱子是经典游戏的原生实现，未复用第三方代码。

关于推箱子

推箱子怎么操作？

方向键或 WASD 移动角色。走到箱子旁边向箱子方向移动即可推动。Z 撤销，R 重置。

可以撤销吗？

可以，按 Z 撤销上一步，支持多步撤销。按 R 重置当前关卡。

有多少关？

内置 50 个经典关卡，难度递增。

成绩保存在哪里？

每关最少步数保存在浏览器 localStorage 中。
