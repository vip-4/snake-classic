直接回答

塔防是什么？

塔防（Tower Defense）是一个免费的浏览器策略游戏。在地图上建造炮塔，防守波次敌人。支持 4 种塔类型（基础、狙击、冰霜、炸弹），每种塔可升级 3 级。敌人波次递增，难度逐步提升。

游戏使用 Canvas 2D 渲染。敌人沿固定路径移动，炮塔自动攻击范围内敌人。金币用于建造和升级，生命值减少到 0 游戏结束。

In English: Tower Defense is a free browser strategy game. Build towers to defend against waves of enemies.

怎么玩塔防

  1. 选择塔：从底部选择炮塔类型。
  2. 放置：点击地图空地放置炮塔。
  3. 升级：点击已有炮塔进行升级。
  4. 开始波次：点击开始按钮释放敌人波次。

核心规则

  • 4 种塔：基础、狙击、冰霜、炸弹
  • 每种塔可升级 3 级
  • 敌人沿固定路径移动
  • 炮塔自动攻击范围内敌人
  • 生命值减少到 0 游戏结束

塔防是经典游戏的原生实现，未复用第三方代码。

常见问题

关于塔防

塔防怎么操作？

点击选择塔类型，再点击地图放置。点击已有炮塔可升级。

有哪些塔类型？

基础炮塔（均衡）、狙击塔（高伤远射）、冰霜塔（减速）、炸弹塔（范围伤害）。

波次怎么触发？

点击「开始波次」按钮释放敌人，也可以自动模式。

成绩保存在哪里？

最高波次保存在浏览器 localStorage 中。
