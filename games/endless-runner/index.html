跑酷是什么？

跑酷（Endless Runner）是一个免费的浏览器动作游戏。角色自动奔跑，你需要跳跃/滑铲/二段跳躲避障碍，收集金币。视差背景，程序化地形生成，速度随距离递增。

游戏使用 Canvas 2D 渲染。支持键盘（空格/↓）和触屏操作。最高分和最远距离保存在浏览器本地。

In English: Endless Runner is a free browser action game. Auto-run, jump, slide, double-jump, collect coins and dodge obstacles.

怎么玩跑酷

  1. 跳跃：空格或点击屏幕跳跃。
  2. 二段跳：空中再次按空格进行二段跳。
  3. 滑铲：按 ↓ 或 S 滑铲躲避高障碍。
  4. 收集：收集金币增加分数，躲避障碍物。

核心规则

  • 角色自动奔跑，速度随距离递增
  • 低障碍需跳跃，高障碍需滑铲
  • 双层障碍需二段跳+滑铲
  • 收集金币增加分数
  • 撞到障碍游戏结束

跑酷是经典游戏的原生实现，未复用第三方代码。

常见问题

关于跑酷

跑酷怎么操作？

空格/点击跳跃，二段跳，↓/S 滑铲。手机点击屏幕跳跃。

有几种障碍？

低障碍（需跳跃）、高障碍（需滑铲）、双层障碍（需二段跳+滑铲）。

速度会加快吗？

是的，随距离增加速度递增，难度逐步提升。

成绩保存在哪里？

最高分和最远距离保存在浏览器 localStorage 中。
