打砖块是什么？

打砖块（Breakout）是一个免费的浏览器动作游戏。控制底部挡板反弹小球，击碎上方所有砖块。支持多关卡、道具掉落（加长挡板、多球、激光、减速）、生命系统。鼠标、触屏、键盘都能操作。

游戏使用 Canvas 2D 渲染，支持 AABB 碰撞检测、粒子爆炸效果、道具系统。最高分保存在浏览器本地。

In English: Breakout is a free browser action game. Control the paddle to bounce the ball and smash all bricks.

怎么玩打砖块

  1. 移动挡板：鼠标或手指在画面上移动，或按 ← → 键。
  2. 反弹小球：让小球撞到挡板反弹，击碎上方砖块。
  3. 收集道具：击碎砖块可能掉落道具，用挡板接住即可生效。
  4. 通关：击碎所有砖块进入下一关。小球落底失去一命。

核心规则

  • 控制挡板反弹小球，击碎所有砖块
  • 小球落底失去一命，共 3 条生命
  • 击碎砖块可能掉落道具
  • 击碎所有砖块进入下一关
  • 道具：加长挡板、多球、激光、减速、额外生命

打砖块是经典游戏的原生实现，未复用第三方代码。

常见问题

关于打砖块

打砖块怎么操作？

鼠标或手指在画面上移动挡板，或按 ← → 键。空格发球/暂停。

道具怎么收集？

击碎砖块可能掉落道具，用挡板接住即可生效。

有多少关？

无限关卡，每关砖块布局不同，难度递增。

成绩保存在哪里？

最高分保存在浏览器 localStorage 中，不会上传服务器。
