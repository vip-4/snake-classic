贪吃蛇经典版是什么？

贪吃蛇经典版（Snake Classic）是一个免费、开源、可直接在浏览器中游玩的轻量级 Snake 游戏。它在 20×15 的网格上进行，蛇每 150 毫秒移动一格，吃到食物加 10 分，撞到自己游戏结束，越过边缘会从对侧出现。页面为纯静态 HTML/CSS/JavaScript，无广告、无追踪、无需登录。

本作把 Simple Game Tutorials 的 Snake 教程规则完整搬到 Web：用方向队列避免快速按键导致的自撞，食物只生成在空白格，最高分保存在浏览器本地。整个过程不请求任何第三方接口，首次加载后可离线游玩。

In English: Snake Classic is a free, open-source, zero-dependency Snake game playable in any modern browser. It uses a 20×15 grid, a 150 ms tick, wrap-around edges, and a locally stored high score.

怎么玩贪吃蛇经典版

  1. 开始：点击“开始游戏”，或直接按任意方向键。
  2. 转向：用方向键 / WASD 控制蛇头，不能直接掉头。
  3. 吃食物：让蛇头碰到红色方块，每次加 10 分并增长一格。
  4. 活下去：撞到自己的身体即结束；越过边界会从对侧穿出。

核心规则

  • 网格固定为 20 × 15，每格 24 像素。
  • 蛇每 150 毫秒移动一格，速度恒定。
  • 吃到食物 +10 分，蛇身增长一格。
  • 食物只会出现在未被蛇占据的格子。
  • 蛇头撞到自身判定失败。
  • 移动方向进入队列，快速连按不会误触发掉头。

规则与数据结构参考 Simple Game Tutorials 的公有领域 Snake 教程，使用原生 JavaScript 独立实现。

常见问题

关于贪吃蛇经典版

贪吃蛇经典版是免费的吗？

是。游戏完全免费，没有广告、内购或付费墙，也不需要注册账号。代码以 MIT 协议开源。

可以在手机上玩吗？

可以。页面采用响应式布局，手机和平板可直接游玩；支持在游戏画面上滑动转向，也可以点击屏幕下方的方向键。

需要下载或安装吗？

不需要下载。游戏是纯静态网页，打开即玩；在支持的浏览器中还可以“添加到主屏幕”，首次加载后可离线游玩。

最高分会保存在哪里？

最高分保存在浏览器本地存储（localStorage）中，不会上传到服务器。清除浏览器数据或更换设备后记录会丢失。

游戏用了什么技术？

使用原生 HTML、CSS、JavaScript 和 Canvas 2D 绘制，没有任何第三方框架或运行时依赖。首屏 HTML/CSS/JS 约 66 KB，gzip 后约 18 KB。

可以二次开发或商用吗？

可以。代码采用 MIT 许可证，允许修改、分发和商业使用，只需保留版权与许可声明；页面文字内容采用 CC BY 4.0，转载时请注明来源。

娱乐场演示使用真钱吗？

不。21 点、轮盘和视频扑克都是免费演示，只用没有货币价值的虚拟筹码。页面没有任何充值、提现、转账或奖品兑换功能，也没有广告或注册要求。

三款娱乐场演示用了什么规则？

21 点：6 副牌牌靴、庄家所有 17 点停牌、21 点按 3:2 赔付、最多分 4 手、分 A 自动停牌。轮盘：欧式单零 37 格，直注 35:1、打线/列 2:1、红黑奇偶单双 1:1。视频扑克：9/6 杰克或更高赔付表，1–5 分下注，5 分皇家同花顺按每分 800:1 赔付。
