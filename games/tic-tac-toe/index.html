井字棋是什么？

井字棋（Tic Tac Toe）是一个免费的浏览器益智对战游戏。3×3 棋盘，X 方先手，O 方后手，轮流落子。先在横向、纵向或对角线连成3个同色符号者获胜。

游戏使用原生 JavaScript 实现。支持双人同屏对战、胜负与平局计分统计。

怎么玩井字棋

  1. 轮流落子：X 方先手，O 方后手。
  2. 选择格子：点击空格放置自己的符号。
  3. 连成3：横向、纵向或对角线连成3个同色符号获胜。
  4. 平局：棋盘填满未分胜负则平局。

核心规则

  • 3×3 棋盘，X 方先手，O 方后手
  • 轮流在空格放置符号，不可覆盖已占格
  • 横向、纵向或对角线连成3个同色符号即获胜
  • 棋盘填满未分胜负则平局
  • 记录双方胜负与平局次数
  • 井字棋是经典游戏的原生实现，未复用第三方代码

常见问题

关于井字棋

井字棋怎么操作？

点击空格落子，X 方先手，O 方后手，轮流放置符号。

支持几人游戏？

双人同屏对战，同一台设备。

胜负规则？

横向、纵向或对角线连成3个同色符号即获胜，填满未分胜负为平局。

成绩保存在哪里？

双方胜负和平局记录保存在浏览器 localStorage 中。
