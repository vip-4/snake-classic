康威生命游戏是什么？

康威生命游戏（Conway's Game of Life）是一个零玩家游戏（cellular automaton）。在一个无限网格上，每个细胞根据周围 8 个邻居的状态决定下一帧的生死：存活细胞邻居 2-3 个继续存活，否则死亡；死亡细胞邻居恰好 3 个则复活。

游戏使用 Canvas 2D 渲染。支持交互式编辑、预设图案（滑翔机、轻型飞船、脉冲星、滑翔机枪）、速度调节（1-60 帧/秒）、缩放、清空、随机生成。所有状态保存在浏览器内存中。

In English: Conway's Game of Life is a zero-player cellular automaton. Edit the grid, watch cells evolve by simple rules.

怎么玩康威生命游戏

  1. 编辑：点击/拖动在画布上绘制活细胞。
  2. 运行：点击播放按钮开始演化。
  3. 预设：选择预设图案快速体验。
  4. 控制：调节速度、缩放、清空或随机生成。

核心规则（B3/S23）

  • 存活细胞：邻居 2-3 个存活 → 继续存活
  • 存活细胞：邻居 <2 或 >3 → 死亡
  • 死亡细胞：邻居恰好 3 个 → 复活
  • 每次更新所有细胞同时计算

康威生命游戏是经典细胞自动机，未复用第三方代码。

关于康威生命游戏

生命游戏的规则是什么？

存活细胞邻居 2-3 个继续存活，否则死亡；死亡细胞邻居恰好 3 个复活。

可以自定义初始状态吗？

可以，点击/拖动在画布上绘制活细胞，或选择预设图案。

支持哪些预设图案？

滑翔机、轻型飞船、脉冲星、高斯帕滑翔机枪等经典图案。

可以保存状态吗？

当前状态保存在浏览器内存中，刷新页面会重置。
